# サーバA

フロントエンドとバックエンドからなる Web アプリです。

## 構成
- `backend/` : Express を用いたバックエンド
- `frontend/` : 静的ファイル (HTML/CSS/JS)

## 実行方法
1. `serverA` ディレクトリで依存関係をインストールします。
   ```bash
   cd serverA
   npm install
   ```
2. バックエンドを起動します。
   ```bash
   npm start
   ```
   または直接 `node backend/app.js` を実行しても起動できます。
