# サーバA

フロントエンドとバックエンドからなる Web アプリです。

## 構成
- `backend/` : Express を用いたバックエンド
- `frontend/` : 静的ファイル (HTML/CSS/JS)

## 実行方法
1. ルートディレクトリで依存関係をインストールします。
   ```bash
   npm install
   ```
2. サーバAのバックエンドを起動します。
   ```bash
   cd serverA/backend
   node app.js
   ```
   またはリポジトリのルートで次を実行しても起動できます。
   ```bash
   npm start
   ```
