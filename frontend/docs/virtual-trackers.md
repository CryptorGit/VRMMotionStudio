# バーチャルトラッカー（11点）

この機能は、実機センサーの代わりに 11 点のトラッカーを 3D ビューア上に表示し、マウス左ドラッグで移動してポーズを操作できます。

- 各トラッカー（Head, Chest, Hips, L/R Hand, L/R Elbow, L/R Foot, L/R Knee）は色付きの球として表示されます。
- サイドバー > 表示管理 に「バーチャルトラッカー」のトグルがあります。ON で表示、OFF で非表示になります。
- 位置リセットボタンでトラッカーを現在のアバターの骨（VRM Humanoid）の位置に合わせ直します。
- ドラッグは左クリックのみ。ドラッグ中はカメラ操作を一時停止します。
- 簡易 IK（2 ボーン近似）で、手足・胸・頭の向きをトラッカーに追従させます。
  - Hips はトラッカー位置へアバターのルートを平行移動します。
  - Chest/Head はターゲット方向へ回転します。
  - Arm/Leg は肘／膝の極（Elbow/Knee）を参照して自然な曲がりになるように解きます。

注意:
- 本 IK はリアルタイム編集向けの簡易実装です。複雑な制約や貫通防止は行いません。
- VRM のボーン命名や階層が大きく異なるモデルでは精度が落ちる場合があります。
