# セキュアサーバ

本ディレクトリは、セキュリティを要する処理やブラウザだけでは実行が困難な重い処理をサーバ側で担当するための土台です。

## 構成
- `python/ai/` : 高精度姿勢推定や音声→歌声変換、画像→動画生成などの AI 処理
- `java/rendering/` : 高解像度オフラインレンダリングや動画エンコード、VMD/PMX と glTF の大規模変換
- `db/` : 有料会員やユーザーデータを管理するデータベース関連

今後、これらのディレクトリに各種サービスやスクリプトを実装予定です。

## 実行方法
各サービスは対応するサブディレクトリで実行します。例:
- Python AI サービス: `cd python/ai/pose_estimation && python main.py`
- Java レンダリング: `cd java/rendering/offline_render && ./gradlew run`

詳細な手順は各サブディレクトリに今後追加される README を参照してください。
