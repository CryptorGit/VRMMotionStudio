# 仮想トラッカー位置情報と MMD ボーン対応表

本資料では、現実の VR トラッカーではなく、画面上に表示される仮想トラッカーをマウスで操作する想定である。

将来的なモーショントラッキング機能の基礎資料として、画面上に表示される 11 個の仮想トラッカーをマウス操作で配置し、それぞれの位置と MMD ボーンの対応をまとめる。

## 11 仮想トラッカーの位置

11 個の仮想トラッカーはマウス操作で以下の位置に配置する。

1. 頭部（HMD 仮想トラッカー）
2. 胸部の仮想トラッカー
3. 腰部の仮想トラッカー
4. 左肩の仮想トラッカー
5. 右肩の仮想トラッカー
6. 左ひじの仮想トラッカー
7. 右ひじの仮想トラッカー
8. 左ひざの仮想トラッカー
9. 右ひざの仮想トラッカー
10. 左足首の仮想トラッカー
11. 右足首の仮想トラッカー

## 仮想トラッカーと MMD ボーンのマッピング

以下はマウス操作で配置する仮想トラッカーと MMD ボーンの対応表である。

| 仮想トラッカー名 | 位置 | 対応する MMD ボーン |
| --- | --- | --- |
| HMD | 頭部 | 頭 |
| Chest | 胸部 | 上半身 |
| Waist | 腰部 | 下半身 |
| Left Shoulder | 左肩 | 左肩 |
| Right Shoulder | 右肩 | 右肩 |
| Left Elbow | 左ひじ | 左ひじ |
| Right Elbow | 右ひじ | 右ひじ |
| Left Knee | 左ひざ | 左ひざ |
| Right Knee | 右ひざ | 右ひざ |
| Left Ankle | 左足首 | 左足首 |
| Right Ankle | 右足首 | 右足首 |
