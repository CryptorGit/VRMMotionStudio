# VR トラッカー位置情報と MMD ボーン対応表

将来的なモーショントラッキング機能の基礎資料として、VR システムで使用する 11 個のトラッカーの位置と MMD ボーンの対応をまとめる。

## 11 トラッカーの位置

1. 頭部 (HMD)
2. 胸部
3. 腰部
4. 左肩
5. 右肩
6. 左ひじ
7. 右ひじ
8. 左ひざ
9. 右ひざ
10. 左足首
11. 右足首

## トラッカーと MMD ボーンのマッピング

| トラッカー名 | 位置 | 対応する MMD ボーン |
| --- | --- | --- |
| HMD | 頭部 | 頭 |
| Chest | 胸部 | 上半身 |
| Waist | 腰部 | 下半身 |
| Left Shoulder | 左肩 | 左肩 |
| Right Shoulder | 右肩 | 右肩 |
| Left Elbow | 左ひじ | 左ひじ |
| Right Elbow | 右ひじ | 右ひじ |
| Left Knee | 左ひざ | 左ひざ |
| Right Knee | 右ひざ | 右ひざ |
| Left Ankle | 左足首 | 左足首 |
| Right Ankle | 右足首 | 右足首 |
